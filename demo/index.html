A human state is never one signal.

CIRCLE studies what gives a system grounds to act on the body. Guidance waits for agreement between pulse and skin conductance, sufficient signal quality, and a sustained observed state, and every action and every refusal keeps its evidence.

The question

What would make a system that responds to the body worthy of trust?

A rise in heart rate is one observation. A rise in skin conductance is another. Neither, alone, is a reason to act. CIRCLE makes the question testable: start with simulated sensor records, follow quality-gated decisions into bounded feedback, and inspect the evidence behind each response or refusal.

Replay a session, compare active and sham conditions, or independently reconstruct its results from the exported record. These are research tools, not validated physiological measurements or evidence of a therapeutic effect.

01 · Method

Five stages. Each one keeps its own evidence.

  1. 01

    Observe

    Raw skin conductance (EDA), optical pulse (PPG), motion (IMU), and synchronization records: device times, sequence numbers, availability, and declared gaps.

  2. 02

    Infer

    Recovered physiological features, with lineage to the exact samples used.

  3. 03

    Decide

    State, input cutoff, formula components, and explicit outcomes for acting, holding, or stopping.

  4. 04

    Intervene

    The scheduled command, the electrical onset, and the vibration detected from IMU samples.

  5. 05

    Reconstruct

    Analysis and derived records rebuilt from raw inputs, followed by an explicit replay verdict.

Three rules make the loop inspectable

A decision can use only evidence available at the time.

A sample must have been available by the decision time and taken at or before the input cutoff. FIFO stalls, delayed delivery, and missing samples remain visible in the record.

Holding is a decision.

Motion, poor contact, stale data, or disagreeing pathways can prevent guidance. After impairment, the controller requires a full clean 40-second evidence window before treating an elevated state as sustained; repeated quality loss during guidance stops it.

Each stage earns its own evidence.

A command does not prove vibration, and vibration does not establish a physiological effect. PHYSICALLY_OBSERVED requires an observation record; in this test bench, that observation is simulated too.

    05 · Human authority

    Who has authority to turn a proposal into a change?

    A restricted proposal becomes an immutable envelope: its mutation, proposal timestamp, state-history hash, action UUID, and an empty signature slot. It waits as data while the loop continues processing telemetry.

    1. PENDING_SIGNATURE

      The proposal is registered; telemetry continues; the mutation waits.

    2. EXECUTED

      Consent verifies against the registered Ed25519 human public key; the signature and execution frame are recorded.

    3. REJECTED

      Proposal, consent, or execution checks fail. No automatic retry follows.

    Current boundary. The gate is standalone; the physiological controller and protocol runner do not yet route through it. In the workbench, audio feedback is the restricted mutation: proposed, signed, revocable, and hash-linked in a durable log. Consent integration contract

    07 · Boundaries

    What CIRCLE does not claim.

    It cannot tell what someone is feeling.

    An arousal index is an engineering trigger. Physiological signals alone cannot establish a person’s emotion, intent, diagnosis, or consciousness. The twin is phenomenological and not fitted to any person.

    A passing audit is not a measurement of the world.

    It establishes that an export satisfies the checked contracts and agrees with independent reconstruction from its raw inputs, not that those inputs describe reality or that an intervention caused a change.

    No frequency is claimed to cause a state.

    Audio and visual feedback are presentations of recorded evidence, not a demonstrated physiological effect. The twin assumes paced breathing changes its simulated physiology; effects in people would need separate evidence.

    It is not approved for fabrication or human connection.

    No physical sensor, bench, electrical-safety, EMC, or human-outcome validation has been performed. All physiological results shown here come from simulation.

    08 · Run it yourself

    Reproduce every number on this page.

    Python 3.11+ and Git. No device, account, API key, or model server.

    Terminal
    git clone https://github.com/topherchris420/circle.git
cd circle
python -m pip install -r requirements.txt
python tools/run_workbench.py
    Session, sham comparison, and independent audit
    python tools/run_physiology_twin.py --output outputs/physiology --audit

    Every downloaded evidence bundle ships verify_replication.py and the code it rebuilds with, so it runs without this repository (Python 3.11+ with numpy and jsonschema): it recomputes every hash, rebuilds the analysis and every decision from the raw samples, and names the verdict.
